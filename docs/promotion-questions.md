# Promotion questions for the CFS team

The configurator works out the price of a bed with its options, and Shopify then applies its own
discounts at checkout. We have proved percentage discounts (automatic, and by code). Please answer
the questions below so we can test the promotions you really run before launch. Short answers, or
real examples from past sales, are fine.

## 1. What kinds of promotion do you run?

Tick all that apply, and add any we have missed.

- [ ] Percentage off a bed (for example 10% off all beds), automatic
- [ ] Percentage off with a code typed at checkout
- [ ] Fixed amount off (for example £50 off)
- [ ] Free or cheaper delivery
- [ ] Buy one thing, get another cheaper or free (for example a free mattress topper with a bed)
- [ ] Bundle or set price (for example a bed and mattress together for one price)
- [ ] Discount on a spend threshold (for example 10% off orders over £1,000)
- [ ] First-order or email-signup discount
- [ ] Trade or staff pricing
- [ ] Sale periods that change many prices at once
- [ ] Other:

## 2. For each one, tell us

1. **What does it apply to?** Whole order, only beds, only certain beds, only the base bed or also
   the options (drawers, fabrics) and accessories?
2. **How does the customer get it?** Automatic, a code, a link, or staff-applied?
3. **Can it combine** with other promotions or codes? Which ones?
4. **Dates:** is it always on, or time-limited?
5. **Example:** one real case with the bed, options, discount and the final price the customer
   should pay.

## 3. Cases that need a clear rule

- Does a percentage discount apply to the options (a drawer, a fabric) or only to the base bed?
  Today the discount applies to the whole configured line, options included.
- Do discounts apply before or after delivery is added?
- If a promotion changes the bed's base price in Shopify (a sale price), should the options stay at
  their normal price?
- Are there any promotions that must never apply to configurable beds?

## Why we ask

These are not yet tested: unequal sizes, order-level discounts, shipping discounts, and
buy-one-get-one or bundle promotions. Each real promotion type will be tested on the development
store, and the result recorded in `docs/ACCEPTANCE.md` section 3.
