Option Import: Simple Guide

How to add or change a bed's options (fabrics, drawers, lights and so on) from an Excel sheet, without a developer.

1. What this tool does

Every configurable bed has options: for example the drawer choices, the fabric choices and the extra lights. The Option Import tool lets you change those options by filling in an Excel sheet and uploading it.

It has two pages in the app's left-hand menu:

PageWhat it is for
Options importGet the sheet, upload it, check it, and press Import.
Import historySee what was imported before, and undo it with Restore if it was a mistake.
You cannot break anything by previewing. Preview only reads. Nothing in the shop changes until you press Import yourself.

Before you start, you need:

  • The CFS product ID of each bed, for example 146477. (It is the number in the middle of the SKU: CFS-146477-17019159.)
  • The bed must already exist in Shopify with its sizes. This tool changes options only. It cannot create products or sizes.
  • Importing must be switched on for the store. If it is not, you can still preview, but the Import button will not appear. Ask the developer to switch it on.

2. The Excel sheet, in plain words

The sheet is an Excel file (.xlsx) with two tabs. Keep the tab names exactly Groups and Choices, and do not rename the column headings.

  • Groups tab = the headings a shopper sees, such as "Select Drawer" or "Select Fabric". One row per heading.
  • Choices tab = the things to pick under each heading, such as "with 2 Drawer" or "Carlton Black". One row per choice.

Groups tab: one row per heading

ColumnMust fill?What to type
CFS product IDYesThe bed's number, e.g. 146477
GroupYesThe heading name, e.g. Select Fabric
Display orderYesPosition on the page: 1, 2, 3 ...
RequiredYesYes if the shopper must pick something, No if it is optional
Choose afterNoIf this heading only appears after another is picked, type that other heading's name. Otherwise leave blank.
TypeYesChoose one (pick one thing) or Add-on with quantity (pick several, e.g. 2 lights)
Max quantityAdd-ons onlyThe most a shopper can take of one add-on, e.g. 5. Leave blank for "Choose one".

Choices tab: one row per choice

ColumnMust fill?What to type
CFS product IDYesThe bed's number
GroupYesThe heading it belongs to. Must match a heading on the Groups tab exactly.
ChoiceYesThe name the shopper sees, e.g. Carlton Black
Display orderNoWhere the choice sits within its group: 1 is first, 2 is second, and so on (whole numbers). Start again at 1 in each group. Two choices in the same group cannot share a number. Choices with no number come after the numbered ones, in sheet order. If you number nothing, the sheet's row order is used.
Price (£)YesExtra cost in pounds, e.g. 89.99. Type 0 if it is included in the price.
SizesNoOnly offer it on some sizes: type the size IDs with ; between them. Blank = every size.
Size pricesNoA different price on certain sizes, e.g. 17019161=99.99; 17019162=109.99
CFS choice IDNoCFS's own reference number for the choice. Keep it the same each time so old orders still match.
Option codeNoUse when the same option (e.g. a fabric) is used on several beds. Give it the same code everywhere, e.g. FAB-CARLTON-BLACK (letters, numbers and hyphens only).
Image URLNoA full web address starting with https://. A bare file name will be refused.
DetailsNoSmall text under the choice, e.g. dimensions such as W 32cm x H 27cm x D 6cm. Type <br> for a new line.
Inside colourNoA second line of small text under Details, e.g. Texline (Natural Color Linen Look) A0066. Leave it blank to keep what the choice has now. Type new text to replace it. You cannot clear it from the sheet. Older sheets without this column still work.
Cost priceNoWhat the choice costs us, in pounds, e.g. 40.00. Works like Price (£): it applies on every size the choice is offered on. Staff only; shoppers never see it. Blank keeps the current cost.
Size cost pricesNoA different cost on certain sizes, written like Size prices: 17019161=45.00; 17019162=50.00
Supplier cost priceNoWhat the supplier charges for the choice. Same rules as Cost price.
Size supplier cost pricesNoSupplier cost on certain sizes: 17019161=38.00
About the cost columns. They are all optional, and an old sheet without them still works. A blank cell never erases a cost: it keeps what is saved now. To change a cost, type the new number. A size listed in a size-cost column must also be in Sizes when Sizes is filled in. If a cost is higher than the selling price on some size, the preview shows a yellow "Check these" warning (a likely typo), but you can still import. Costs are saved on the bed in a staff-only field, and Download current options includes them.
The most important rule: the sheet is a bed's complete list of options. Anything that is on the bed now but not in your sheet will be removed. This is why the easiest way to change something is to download the current options first (see step 3 below), edit them, and upload the whole thing again.

3. How to use the Options import page, step by step

Open the app, then click Options import in the left menu.

A. Get a sheet to work from (pick one)

1
To change a bed that already has options (most common): "Download current options" Find the box called CFS product IDs (lower down the page). Type one or more bed numbers, separated by commas, spaces or new lines, for example 146477, 69733 (up to 100). Click Download current options. You get an Excel file showing exactly what those beds have right now. Nothing is changed.
2
To set up a bed from scratch: "Download sample" Click Download sample at the top of the page. You get an Excel file with the right columns and a few example rows. Copy the pattern for your own bed, and delete the example rows.
If a bed number is not found in Shopify, nothing downloads and a red message names the bed. Check the number and try again.

B. Edit the sheet in Excel

3
Make your changes Change a price, add a fabric row, delete a row you no longer want, and so on. Follow the column guide in section 2. Save the file as .xlsx.

C. Preview (this changes nothing)

4
Choose the file At the top of the page, click the file chooser and select your saved Excel file.
5
Click Preview The app checks every row against the real Shopify bed and its sizes. This can take a little while if the sheet is big. Please wait.
6
Read the result banner It will be one of these three:
Ready to import: N productsAll good. Every row is correct and every bed would be ready to sell. You may go on to Import.
Not ready: fix the problems belowSomething is wrong. A list of problems appears with the sheet name and row number for each. Fix them in Excel, then choose the file again and press Preview again. Nothing has been changed.
Nothing to importThe sheet is identical to what the shop already has. There is nothing to do.
7
Look at each bed's tab Each bed has its own tab under Products. It shows its groups, its choices, and the price on every size. Beds with a problem are marked. Useful messages you may see:
  • "Fix these rows for this product" (red): you must fix these rows before importing.
  • "Check these" (yellow): a warning only. For example, a choice has the same name as an option that already has a code on another bed. Add the code if it is the same option.
  • "Will remove N choices not in the sheet": those choices are on the bed now but missing from your sheet. If that is a surprise, stop and fix the sheet.
  • "No changes; this product will be skipped": nothing to do for this bed.

D. Import (this changes the shop)

8
Click Import When the banner is green, a blue Import N products button appears. Press it. The app first backs up every bed, then writes the new options. You will see a progress bar.
If you change the file after previewing, the button disappears. That is on purpose: choose the file again and press Preview again, so you only ever import what you have checked.
9
Read the result for each bed
ImportedDone. The bed has its new options and is ready to sell.
Written, not readyThe options were written but the bed is not ready to sell yet. Open Products to see why.
Not changedThat bed failed and was left exactly as it was. The reason is shown. Fix it and try again. If the reason says the bed "was changed in Shopify after it was checked", someone edited it while the import was running: press Preview again and re-import.
Check this productThe import stopped part-way for this bed, so we cannot be sure which options it has. Go to Import history and press Restore next to it to put it back to how it was before. The bed is never left half-written, so Restore is safe either way.
A bed is never left half-written: it either gets all of its new options or none of them.
Only one import can run at a time for a store. If you see "Another import is running", wait for it to finish, then try again. Please keep the page open until you see the result.

4. How to use the Import history page

Click Import history in the left menu. It lists the last 50 imports and restores, newest first. Each one shows:

  • When it happened and the file name
  • Run by: who did it
  • Each bed that was changed, with its result badge (same badges as above)

How to undo an import (Restore)

1
Find the import in the list.
2
Click Restore next to the bed you want to put back. The bed's options go back to how they were just before that import.
3
Wait for the result. Restore is itself saved in the history, so a restore can be undone the same way.

If an import stops part-way

If the page closes, the app restarts, or something fails mid-import, the import shows Stopped part-way in Import history. Then:

  1. Beds the import had already finished show Imported. Nothing to do.
  2. Beds it had not reached are untouched.
  3. A bed it was working on shows Check this product, with a Restore button. Press it to put that bed back to how it was before the import.
  4. Press Remove leftover options under the stopped import to delete any half-made options that no bed uses. Options a bed is using are never removed.
There is no Restore button when the bed had no options at all before that import (there was nothing to go back to). A backup that has already been restored also cannot be restored again.
Orders already placed are never affected. Their prices and choices were saved when the customer paid and cannot be changed by an import or a restore.

5. Example: change one price

Task: make "with 2 Drawer" cost £99.99 instead of £89.99 on Natural Gold (bed 146477).

  1. Options import: type 146477 in CFS product IDs and click Download current options.
  2. Open the file. On the Choices tab find the row "with 2 Drawer". Change Price (£) to 99.99. Save.
  3. Choose the saved file at the top and click Preview.
  4. Check the Natural Gold tab shows the new price. The banner should say Ready to import: 1 product.
  5. Click Import 1 product and wait for Imported.
  6. If it was a mistake, go to Import history and click Restore.

6. Common problems and what to do

What you seeWhat it means / what to do
"Unknown column" or "Unknown sheet"A tab or heading was renamed. Use exactly Groups and Choices and the original column names.
Product not foundThe CFS product ID does not match any Shopify bed. Check the number against the SKU.
A size ID is not one of the product's sizesA size number in Sizes or Size prices is wrong. Copy it from the SKU: CFS-146477-17019159.
Group not foundThe group name on the Choices tab does not exactly match the Groups tab (check spelling and spaces).
Image URL problemIt must be a full address starting with https://.
"Option code ... is ... on another product; this sheet gives it a different name/image/details"The same option code must have the same name, image and details everywhere. Either match the other bed, or add that bed to the sheet too so both change together.
Price problemPrices must be numbers with up to 2 decimals and not negative.
"Not ready to sell"Some size has no valid way to be priced (for example a required group with no choice on one size). Add the missing choices.
File too largeThe limit is 5 MB, 100 beds per file, and 1,024 choices on one bed. Split it into smaller files.
"Importing is not switched on for this store"Writing is turned off for this store. Preview still works. Ask the developer.
"Shopify could not be asked about shared options just now; try again"A temporary Shopify hiccup. Wait a minute and press Preview again.

7. Golden rules

  1. Always download the current options first when changing an existing bed, so you do not accidentally remove choices.
  2. Always preview and read the banner and each bed's tab before pressing Import.
  3. If anything is red, nothing is imported. Fix the rows named and preview again.
  4. Check "Will remove N choices": it must be what you intended.
  5. Made a mistake? Import history, then Restore.
  6. Keep CFS choice ID and Option code the same from import to import.
